# Supervising-Station Signal Verification

## Required Inputs

- Account number
- Monitoring provider
- Communicator model
- Communication paths
- Receiver destination
- Panel model
- Event-code format
- Test window
- Authorized contacts

Do not store private account credentials, passwords, encryption keys, or receiver access credentials in the knowledge base.

## Signals to Verify

- General alarm
- Waterflow alarm
- Supervisory
- Valve tamper
- System trouble
- AC failure
- Low battery
- Communication failure
- Fire pump running
- Fire pump trouble
- Fire pump phase reversal
- Other project-specific signals

## Verification Record

- Signal sent
- Signal received
- Correct account
- Correct zone or point
- Correct event classification
- Correct timestamp
- Correct restoration
- Monitoring operator confirmation
