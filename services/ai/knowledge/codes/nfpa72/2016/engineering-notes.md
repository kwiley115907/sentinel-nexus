# NFPA 72 — 2016 Edition Engineering Notes

## Document Information

- Standard: NFPA 72
- Edition: 2016
- Publisher: National Fire Protection Association
- Adoption status: Verify for each project
- AHJ amendments: Verify for each jurisdiction
- Official source: Authorized NFPA access or licensed copy
- Last reviewed: Not yet reviewed

## Use Restrictions

This file contains company-created engineering notes and checklists. It is not a reproduction of NFPA 72.

## General Project Verification

Before using this edition on a project, verify:

- The 2016 edition is the adopted edition
- Local amendments
- Project specifications
- Approved drawing revision
- Manufacturer documentation
- Equipment listing
- Sequence of operations
- AHJ requirements

## Initiating Devices

Review:

- Detector type
- Detector model
- Ceiling height
- Ceiling configuration
- Beam depth
- Air movement
- Environmental conditions
- Device listing
- Manufacturer spacing requirements
- Testing accessibility

## Notification Appliances

Review:

- Public or private mode
- Sleeping or nonsleeping area
- Appliance model
- Candela setting
- Wattage setting
- Alarm current
- Synchronization
- Audible coverage
- Visible coverage
- NAC loading
- Voltage drop

## Emergency Control Functions

Review:

- Elevator recall
- Elevator shunt trip
- Door release
- Access-control interface
- HVAC shutdown
- Smoke-control interface
- Fan and damper control
- Suppression interfaces
- Approved sequence of operations

## Engineering Rule

Do not claim code compliance based on this summary alone. Verify requirements in an authorized copy of NFPA 72-2016 and with the AHJ.
