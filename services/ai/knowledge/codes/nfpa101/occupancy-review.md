# NFPA 101 Occupancy and Fire Alarm Review

## Document Control

- Standard: NFPA 101, Life Safety Code
- Edition: Verify per jurisdiction
- Occupancy chapter: Verify
- Local amendments: Verify
- Source: Authorized NFPA access or licensed copy

## Occupancy Identification

Record:

- Primary occupancy
- Incidental occupancies
- Mixed occupancy
- Separated or nonseparated use
- New or existing building
- High-rise status
- Ambulatory or sleeping use
- Number of occupants
- Number of stories
- Special hazards

## Fire Alarm Review

Determine from the authorized adopted edition:

- Whether a manual fire alarm system is required
- Whether automatic detection is required
- Whether occupant notification is required
- Whether emergency voice/alarm communication is required
- Whether monitoring is required
- Whether sleeping-area notification applies
- Whether visible notification applies
- Whether special evacuation or relocation procedures apply

## Documentation Needed

- Occupancy classification
- Occupant load
- Building height
- Floor count
- Sprinkler status
- Construction type
- Egress strategy
- Fire and smoke compartments
- Approved code analysis
- AHJ interpretation

## Engineering Rule

Do not determine system scope solely from a floor plan. Use the approved code analysis and adopted occupancy requirements.
