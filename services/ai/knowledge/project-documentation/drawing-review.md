# Fire Alarm Drawing Review Procedure

## Document Control

Verify:

- Project name
- Project number
- Drawing sheet
- Drawing revision
- Issue date
- Addenda
- Approved status
- Engineer or designer
- AHJ approval status
- Project specifications

## Floor-Plan Review

Check:

- Room names
- Walls
- Doors
- Ceiling types
- Ceiling heights
- Fire barriers
- Smoke barriers
- Shafts
- Stairs
- Elevators
- Mechanical rooms
- Electrical rooms
- Sprinkler rooms
- Fire pump rooms
- Hazardous areas
- Exterior areas

## Device Review

Check:

- Device type
- Device model
- Device address
- Mounting location
- Mounting height
- Coverage
- Accessibility
- Environmental rating
- Circuit assignment
- Drawing symbol
- Schedule entry

## Circuit Review

Check:

- SLC loop
- NAC circuit
- Speaker circuit
- Telephone circuit
- Network circuit
- Auxiliary power
- Interface wiring
- Circuit class
- Survivability
- Source terminal
- Cable designation
- Wire gauge
- Routing

## Coordination Review

Compare against:

- Architectural plans
- Electrical plans
- Mechanical plans
- Sprinkler plans
- Elevator plans
- Smoke-control plans
- Access-control plans
- Security plans
- Sequence of operations
- Specifications
- Riser diagram
- Point list
- Cable schedule

## Required Output

Record:

- Conflicts
- Missing information
- Assumptions
- RFIs
- Coordination items
- Drawing corrections
- Revision required
- Responsible party
- Due date
