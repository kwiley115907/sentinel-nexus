# Notification Appliance Circuit Planning

Notification appliance circuit planning requires verified appliance and power-supply data.

Important inputs include:

- Power-supply model
- Output terminal
- Nominal source voltage
- Minimum available terminal voltage
- Appliance model
- Appliance setting
- Alarm-current rating
- Synchronization protocol
- Number of appliances
- Circuit topology
- One-way conductor length
- Conductor material
- Conductor gauge
- Manufacturer voltage-drop method
- Minimum appliance operating voltage
- Circuit class
- Survivability requirement
- Approved drawing revision

A generic voltage-drop calculation is not a substitute for the listed manufacturer's calculation method.

Do not assume every appliance on a circuit has the same current. Use the current for each exact model and selected candela or output setting.

Separate assumptions from verified manufacturer data.
