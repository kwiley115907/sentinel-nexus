# Signaling Line Circuit Planning

SLC documentation should identify:

- Control panel or network node
- Loop number
- Circuit class
- Isolation strategy
- Address range
- Device model
- Device address
- Module type
- Floor and area
- Drawing sheet
- Drawing revision
- Conductor type
- Shielding requirement
- Maximum permitted resistance
- Maximum permitted capacitance
- Manufacturer wiring restrictions
- T-tap or branching restrictions
- Survivability requirement
- Test status

SLC limits and topology requirements are manufacturer-specific. Do not infer compatibility or maximum circuit length without verified manufacturer documentation.
