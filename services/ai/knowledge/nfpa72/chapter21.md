# NFPA 72 Chapter 21 — Emergency Control Function Interfaces

## Source

- Standard: NFPA 72
- Edition: TO BE VERIFIED FOR EACH PROJECT
- Chapter: 21
- Official source: NFPA LiNK or an authorized printed/electronic copy
- Last reviewed: NOT YET REVIEWED

## Scope Summary

Chapter 21 addresses fire alarm system interfaces with emergency control functions and other building systems.

This file contains company-created notes and is not a reproduction of NFPA 72.

## Common Emergency Control Interfaces

- Elevator recall
- Elevator shunt trip coordination
- Elevator power shutdown
- Door release
- Door unlocking
- Smoke control
- HVAC shutdown
- Fan control
- Damper control
- Fire pump status
- Generator status
- Suppression system interfaces
- Smoke door release
- Access-control interfaces
- Mass-notification interfaces
- Building automation interfaces

## Elevator Interface Review

Check:

- Primary recall
- Alternate recall
- Machine-room detection
- Hoistway detection
- Shunt-trip sequence
- Power-monitoring requirements
- Heat detector coordination
- Smoke detector coordination
- Required reset behavior
- Interface relay ratings
- Elevator contractor coordination

## Door and Access-Control Review

Check:

- Locked or unlocked normal state
- Required release condition
- Fail-safe or fail-secure behavior
- Fire alarm relay function
- Access-control interface
- Egress requirements
- Door operator coordination
- Power source
- Monitoring requirements

## HVAC and Smoke-Control Review

Check:

- Unit designation
- Fan shutdown or startup
- Damper command
- Proof-of-operation feedback
- Smoke-control sequence
- Firefighter control station
- Priority of commands
- Required supervision
- Mechanical contractor coordination

## Engineering Rule

Never infer an emergency control sequence from device names alone. Use the approved sequence of operations and control matrix.
