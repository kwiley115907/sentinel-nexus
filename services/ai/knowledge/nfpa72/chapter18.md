# NFPA 72 Chapter 18 — Notification Appliances

## Source

- Standard: NFPA 72
- Edition: TO BE VERIFIED FOR EACH PROJECT
- Chapter: 18
- Official source: NFPA LiNK or an authorized printed/electronic copy
- Last reviewed: NOT YET REVIEWED

## Scope Summary

Chapter 18 addresses audible, visible, textual, tactile, and other notification appliances.

This file contains company-created notes and is not a reproduction of NFPA 72.

## Common Notification Appliances

- Horns
- Strobes
- Horn/strobes
- Speakers
- Speaker/strobes
- Bells
- Chimes
- Textual notification appliances
- Tactile notification appliances
- Low-frequency sounders where required

## Audible Notification Review

Check:

- Required sound level
- Ambient sound measurement
- Public/private operating mode
- Sleeping-area requirements
- Low-frequency requirements where applicable
- Appliance output setting
- Door and wall attenuation
- Mechanical noise
- Speaker tap setting
- Message intelligibility where applicable

## Visible Notification Review

Check:

- Room dimensions
- Appliance mounting type
- Wall-mounted or ceiling-mounted
- Candela rating
- Appliance spacing
- Obstructions
- Corridor configuration
- Synchronization
- Sleeping-area requirements
- Appliance listing

## NAC Engineering Review

Check:

- Exact appliance model
- Selected candela or output setting
- Alarm current for each appliance
- Circuit length
- Wire gauge
- Source voltage
- Minimum terminal voltage
- Minimum appliance operating voltage
- Synchronization protocol
- Power-supply compatibility
- Maximum circuit current
- Circuit class
- Survivability requirements
- Manufacturer voltage-drop method

## Engineering Rule

Do not use a generic current value for all horn/strobes. Use the published current for each exact model and selected setting.
