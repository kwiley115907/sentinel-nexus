# Fire Alarm Sequence-of-Operations Control Matrix

## Purpose

The control matrix defines the required system response for each initiating event.

## Input Information

For each input, record:

- Input ID
- Device type
- Device address
- Location
- Alarm, supervisory, or trouble condition
- Associated zone
- Drawing reference

## Output Information

For each response, record:

- General alarm
- Notification appliance activation
- Voice message
- Elevator primary recall
- Elevator alternate recall
- Shunt-trip preparation
- Door release
- Door unlocking
- HVAC shutdown
- Smoke-control function
- Fan startup
- Fan shutdown
- Damper command
- Suppression release
- Monitoring transmission
- Annunciator display
- Event logging
- Other interface

## Verification

Confirm:

- Normal state
- Active state
- Reset state
- Failure state
- Supervisory response
- Trouble response
- Monitoring response
- Required delays
- Required priorities
- Manual override
- Proof-of-operation feedback
- Latching behavior
- Reset requirements

## Engineering Rule

Do not derive the final sequence solely from device names or typical practice.

Use the approved sequence of operations, project specifications, equipment instructions, and coordinated control matrix.
