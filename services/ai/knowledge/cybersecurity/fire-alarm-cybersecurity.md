# Fire Alarm Cybersecurity and Remote Access

## Protected Information

Do not store:

- Panel passwords
- Programming passwords
- Monitoring credentials
- VPN credentials
- Cloud-platform passwords
- Encryption keys
- Customer network passwords
- Static private keys
- Administrator tokens

## Record Safely

Store only:

- Network architecture description
- Approved IP addressing policy
- Port and protocol requirements
- Firmware version
- Patch status
- Remote-access approval status
- Responsible organization
- Backup date
- Recovery procedure
- Access-control policy

## Change Control

Before a remote change:

- Confirm authorization
- Confirm current database backup
- Confirm firmware compatibility
- Confirm affected systems
- Confirm rollback procedure
- Record the person making the change
- Record date and time
- Perform required post-change testing

## Engineering Rule

No AI-generated instruction should authorize an unapproved remote change to life-safety equipment.
