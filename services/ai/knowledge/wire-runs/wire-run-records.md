# Fire Alarm Wire-Run Records

A useful fire alarm wire-run record should include:

- Unique wire-run ID
- Project ID
- Building
- Floor
- Area
- Drawing sheet
- Drawing revision
- Circuit ID
- Circuit type
- Circuit source
- Source terminal
- Circuit class
- Survivability requirement
- Cable designation
- Conductor count
- Wire gauge
- Shielding requirement
- Manufacturer
- Part number
- Start location
- End location
- Intermediate devices
- Estimated route length
- Installed route length
- Junction boxes
- Penetrations
- Device count
- Alarm current
- Calculated voltage drop
- Installation status
- Drawing verification
- Manufacturer-data verification
- Field verification
- Test status
- Notes

Incomplete wire runs must be marked as planning or unverified. Missing cable, circuit-load, routing, or drawing data must be identified before installation release.
